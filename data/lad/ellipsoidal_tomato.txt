# Example leaf angle distribution for HELIOS++ (custom LAD file format)
#
# Format: one line per leaf inclination, "inclination_deg,g_L"
#   inclination_deg: angle between leaf normal and zenith in degrees, [0, 90],
#                    strictly increasing
#   g_L:             probability density of the leaf inclination (non-negative;
#                    HELIOS++ interpolates linearly and normalizes, so the
#                    values do not need to integrate to 1)
# Lines starting with '#' and empty lines are ignored.
#
# Distribution: ellipsoidal (Campbell 1990), in the form given by Bonan (2019),
# p. 30, eqs. 2.11-2.14:
#   g_L(theta_L) = 2 x^3 sin(theta_L) / (Lambda (cos^2(theta_L) + x^2 sin^2(theta_L))^2)
#   Lambda = x + ln((1 + e) / (1 - e)) / (2 e x),  e = sqrt(1 - x^-2)  (for x > 1)
# x is the ratio of the horizontal to the vertical semi-axis of the ellipsoid
# (x = 1: spherical, x > 1: more horizontal leaves, x < 1: more vertical leaves).
#
# Parameter: x = 2.7, used for a tomato canopy (Solanum lycopersicum 'Aranca') by
# Sarlikioti, V., de Visser, P.H.B., Marcelis, L.F.M. (2011). Exploring the
# spatial distribution of light interception and photosynthesis of canopies by
# means of a functional-structural plant model. Ann. Bot. 107(5), 875-883,
# doi:10.1093/aob/mcr006
#
# Campbell, G.S. (1990). Derivation of an angle density function for canopies
#   with ellipsoidal leaf angle distributions. Agric. For. Meteorol. 49, 173-176.
